# Adugemane restaurant website

A responsive, single-page restaurant website inspired by the supplied editorial food-site reference.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy on Render
1. Push this folder to a GitHub repository.
2. In Render, choose **New + → Static Site** and connect the repository.
3. Set the root directory to the folder containing `index.html` (or leave blank if it is the repository root).
4. Leave **Build Command** empty.
5. Set **Publish Directory** to `.` and deploy.
